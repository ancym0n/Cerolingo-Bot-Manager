Privacy Policy

Last updated:

1. Overview of Data Practices

CerolingoBM is a desktop app that runs on your own computer. It has no servers, no user accounts, and no analytics. It does not send any information to the developer, and nothing you enter in the app ever leaves your device except for the requests to Duolingo and GitHub described below.

2. What Is Stored on Your Device

The app saves your settings (account creator options, XP farm settings, Legit/Hidden/Console mode toggles, and auto solver preferences) in the local storage of the app window. Accounts created by the app are saved to accounts.txt inside the app's user data logs folder (or src/python/logs/accounts.txt when running from source). Each entry contains the email, password, and session token of that account stored as plain text. The Manage Accounts button opens that file in your default text editor.

On first launch, the app also stores its private Python runtime and Playwright Chromium browser inside its user data runtime directory, and caches the downloaded Cerolingo mod menu bundle in cache/solver-bundle.js. Delete these folders or uninstall the app to remove all local data.

3. Network Connections

The app talks to Duolingo (duolingo.com) to register accounts, send XP session requests with your saved tokens, and run interactive or automated lessons in Playwright. What Duolingo does with that traffic is covered by its own privacy policy. The app window also loads the Nunito font from Google Fonts, so Google can see your IP address when it opens.

On first launch, if the local runtime is not set up yet, the app downloads a standalone Python build from GitHub (python-build-standalone), installs playwright, requests, and certifi from PyPI, and downloads a Chromium build via Playwright. When running the Auto Solver or Legit XP Farming, solver.py fetches the latest Cerolingo extension scripts from GitHub (raw.githubusercontent.com/ancym0n/Cerolingo) and caches them locally for offline fallback. On startup, the app also checks GitHub Releases (api.github.com/repos/ancym0n/Cerolingo-Bot-Manager/releases/latest) to offer optional updates. There is no telemetry or crash reporting.

4. Browser Automation

Account creation, Legit XP farming, and the Auto Solver launch Chromium through Playwright (either visible or in Hidden background mode). Every session runs locally with an isolated temporary profile rather than your personal browser profile, so your bookmarks, cookies, and browsing history are never touched. Closing the window or stopping the bot ends the session.

5. This Website

This site does not use tracking cookies or analytics. Your browser loads fonts from Google Fonts, and the page queries the GitHub API and shields.io for the latest release packages, download count, and star count, so those services can see your IP address. The Download Manager caches the latest release metadata in your browser's local storage, and the last updated date is cached in session storage until you close the tab.

6. Core Compliance Declarations

CerolingoBM guarantees the following:

  • No Data Collection or Sale: Nothing from the app is collected, sold, or shared with third parties.
  • No Tracking: The app has no analytics, advertising, or background tracking.
  • You Stay in Control: All saved data is in files on your device, and the full source code is open on GitHub.

7. Changes to This Policy

This Privacy Policy may be updated if the app changes how it handles data. Any updates will be published on this page.
